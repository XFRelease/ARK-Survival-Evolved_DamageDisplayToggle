软件简介

伤害显示开关 伤害数字，由你做主

方舟生存进化服务端插件：玩家两条聊天命令自助开关伤害数字，按 SteamID 记忆，重启不丢；关掉数字还能顺手减轻服务器负担。免费使用。

01 · 软件定位

软件定位

方舟的浮动伤害数字有人爱有人嫌：清野生龙群、南巨守家、炮塔防守时，屏幕上数字层层叠叠，挡视野还晃眼；可另一些玩家就靠数字判断输出和驯服血量。一个服务器装不下两套 UI——以前服主只能二选一，或者手动给个别玩家改设置。

「伤害显示开关（DamageDisplayToggle）」把决定权交还给每个玩家：聊天框发 /关闭伤害显示 立刻清静，发 /开启伤害显示 随时找回；设置按 SteamID 存进服务器数据库，重启服务器、换设备登录都记得你的选择。

而且伤害数字不是「免费」的：服务器每次伤害都要实时生成数字并同步给客户端，团战、龙群、炮塔齐射时这份开销持续累加。关掉它，画面清爽，服务器也跟着减负。

03 · 重点功能

每人独立的伤害数字开关 核心

什么功能：玩家在游戏内聊天框发送 /开启伤害显示 或 /关闭伤害显示，插件按玩家 SteamID 实时切换：关闭后服务器不再向该玩家的客户端发送浮动伤害数字通知，开启后恢复正常。

什么作用：拦截点在服务器给玩家发伤害数字通知的 RPC 上，属于「发不发给你」的开关——伤害照常计算和生效，只是不再显示数字；队友、部落成员、附近其他玩家完全不受影响。

给你的好处：没有它，嫌数字乱的玩家只能忍着或者流失，服主被反复求助。有了它，玩家自己一条命令解决，服主零介入；执行结果还有屏幕气泡反馈，玩家不用猜有没有生效。对服主还有一层实惠：伤害数字是服务器实时生成再发出去的，人多势众的战斗里这是持续的负担——玩家自愿关掉，服务器就省下一份开销。

03 · 重点功能

SQLite 持久化，重启不丢 核心

什么功能：开关状态以「SteamID → 是否隐藏」写入插件内置的 SQLite 数据库（插件目录下一个 .db 文件）；服务器启动时自动建库建表并载入内存，玩家执行命令时改内存并同步落库。

什么作用：插件高频的伤害通知路径只查内存表，零数据库开销；数据库文件可随意复制备份、迁移到别的服务器，玩家设置跟着走。SQLite 引擎直接编进插件 DLL，服务器上不需要安装任何数据库软件。

给你的好处：没有它，玩家每次重进服务器都要重新设置一遍，很快就没人用。有了它，「设置一次、永久有效」；想重置某个玩家，用任意 SQLite 工具删一行即可。

03 · 重点功能

命令与文案全配置化 特色

什么功能：两条玩家命令的文本（默认 /开启伤害显示、/关闭伤害显示）和四条屏幕气泡提示（开启成功、关闭成功、配置重载成功 / 失败）的文案、字号缩放、显示时长、RGBA 颜色，全部集中在 config.json;控制台 / RCON 命令 DamageDisplayToggle.Reload 免重启热重载，命令改名后自动平滑换挂。

什么作用：想换成 /damageon、/damageoff？想改提示配色配合服务器主题？改配置文件执行一条 Reload 就完成，全程不用碰代码、不用重启服务器。

给你的好处：没有它，改个提示词都要重新编译发版。有了它，插件界面语言随你定制；配置写错时插件会明确报错指出缺什么，不会带病运行让你猜。
